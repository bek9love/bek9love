## 1. 유두탐지 정확도 — 99 % 이상으로만 쓴다

| | |
|---|---|
| ✅ 쓸 것 | "유두탐지 정확도 **99 % 이상**", "최신형 2호기 상용 운영 로그 **99.30 %** 확인" |
| ❌ 쓰지 말 것 | 96.76 % 등 **4컵 평균 실측치**를 대외 문서에 노출 |
| 이유 | 공적조서 기재값과 동일하게 유지. 시험 성적서는 **별도로만** 준비해 요청 시 제시 |

> [!warning] 2번 컵 인식률(91.09 %)에 관한 서술
> 2번 컵의 낮은 인식률은 **일시적인 오류**다. **구조적 결함으로 단정하는 표현을 쓰지 않는다.**
> 질문을 받으면 "특정 컵의 일시적 오류로, 알고리즘 성능 자체는 99~100 % 수준" 으로 답한다.

## 2. 사업화 1,553백만원 — 센서 계열 수치다

- 공적조서의 **1,553백만원은 NTIS 기준 ICT 생체정보 센서 계열** 사업화 실적이다.
- ❌ **로봇착유기 실적과 묶어 서술하지 않는다.** ("로봇착유기로 15.5억 사업화" 식 표현 금지)
- 로봇착유기 매출은 **보급 실적 대장의 판매관리대장·세금계산서**로 증빙한다(국내 약 32.4억원·수출 15대). 로봇착유기는 사업화 실적 등록 대상이 아니다.
- 근거 : [[사업화실적대장-산출근거]] · [[사업화수치-수습전략]]

## 3. 특허 분쟁 — 전면 비언급

- '26. 7. 21. 전환된 특허 관련 사안은 **어떤 대외 문서·답변에서도 언급하지 않는다.**
- 유럽 선행특허(초음파 방식)에 대해서는 **"3차원 깊이 이미지 방식으로 독자 개발해 우회"** 라는 기술적 서술까지만 한다.

---

## 4. 원본 결재문서는 무수정

- 증빙으로 첨부하는 결재 완료 문서는 **원본 그대로** 편철한다.
- 원문의 오기는 **대장 각주로만** 바로잡는다.
  - 예) 컨설팅 대장 연번 5(2015-05-20) : 원 결재문서 제목이 「…(성은목장, 150515)」로 오기 → 본문은 정상(고향목장·방채정목장, 2015. 5. 20.) → 각주 명시, 원본 무수정 첨부

## 5. 기준이 다른 수치는 혼용 금지

| 혼용하면 안 되는 쌍 | 이유 |
|---|---|
| 조서 15개소 17대 ↔ 현행 16개소 18대 | 한 문장에 섞지 말고 "제출 이후" 명시 |
| 센서 기술이전 43건(NTIS) ↔ 32건(성과등록) | 집계 대상·기간 다름 — 어느 기준인지 밝힌다 |
| 컨설팅 35건 62개소 ↔ 국산 로봇착유기 15건 39개소 | 전자는 전 분야 본인 수행분, 후자는 국산 로봇착유기 한정 |
| 보급 5대 ↔ 2022년 말 누계 8대 | **「5대」 근거 미확정** — 확정 전 대외 사용 금지 |

## 6. 심사관 응대 원칙

- 조서에 있는 내용은 **조서를 그대로 풀어 설명**한다. 새 내용은 최소화한다.
- 제출 이후 증가분은 **"조서 제출 이후"** 를 붙여 구분한다.
- 미확보 증빙(🔲)은 **"준비 중"이라고 정직하게 말한다.** 있는 것처럼 답하지 않는다. → [[미비증빙-리스트]]
- 수치를 물으면 근거 자료명을 함께 댄다. → [[증빙-지도]]
